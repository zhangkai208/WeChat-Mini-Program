# 今日人设 / 整活运势 小程序 · 设计文档

- **创建日期**：2026-07-16
- **平台**：微信小程序 + 腾讯云开发（CloudBase）
- **项目性质**：学习练手（基于腾讯云开发 6 个月试用）
- **开发者基础**：有微信小程序开发经验，未接触过云开发

---

## 1. 项目概述

一个微信小程序：用户输入名字（可选星座、心情），由 AI 生成一份带有网感的「今日人设 + 运势 + 宜忌」，可保存历史、生成图片分享、每日打卡。

**核心价值**：以一个有趣、有传播性的小项目为载体，练熟腾讯云开发的几大能力（云函数、云数据库、云存储、微信登录、云开发 AI）。

## 4. 整体架构

```
【前端】微信小程序（原生）
        首页·生成   历史页   我的页
              │
              │  wx.cloud（云开发 SDK）
              ▼
【后端】云开发 CloudBase
   ├─ 云函数 generatePersona ──调用──▶ 云开发 AI（生成人设运势）
   ├─ 微信登录 ──写入──▶ 云数据库 users
   ├─ 云函数 ──读写──▶ 云数据库 records(历史) / checkins(打卡)
   └─ 生成分享图 ──上传──▶ 云存储
```

**架构红线**：AI 调用必须放在云函数内，禁止在小程序前端直接调用 AI。原因：直接调用会把调用凭证暴露在客户端代码中，导致额度被盗用。

## 5. 前端设计

### 5.1 页面结构

- **首页（生成页）**：输入名字（+可选星座/心情）→ 点「生成今日人设」→ 展示结果卡片
- **历史页**：列表展示历史生成记录（按时间倒序），点击可查看详情
- **我的页**：登录状态、头像昵称、连续打卡天数（阶段 3）

### 5.2 主流程

```
打开小程序 → 微信登录 → 输入名字 → 调云函数生成 → 展示人设运势
            → 自动存入历史 →（阶段2）生成图分享 →（阶段3）每日打卡
```

---

## 6. 后端设计

### 6.1 云函数

| 函数名 | 职责 | 阶段 |
|--------|------|------|
| `generatePersona` | 拼接 prompt → HTTP 调用 AI 接口(url+key) → 解析 JSON → 存 `records` → 返回 | 1 |
| `checkin` | 记录当日打卡、更新连续天数、限制每天一次 | 3 |

> 登录使用云开发自带的微信登录（前端 `wx.cloud` + 云开发用户体系），无需单独写云函数。

**AI 调用方式**：云函数内通过 HTTP POST 调用用户已取得的 AI 服务接口。
- 接口 URL：写入云函数配置（非密钥，可入码）
- API Key：**必须存于云函数环境变量**，运行时读取；禁止硬编码、入库、入日志、入对话

### 6.2 云数据库集合（NoSQL 文档型）

```
users    { _openid(自动), nickName, avatarUrl, createdAt }
records  { _openid(自动), name, constellation, mood,
           persona, fortune, yi:[...], ji:[...], luckScore, date, createdAt }
checkins { _openid(自动), date, streak }   ← 阶段3
```

**关键特性**：
- 云数据库会**自动为每条记录写入 `_openid`**（当前登录用户的微信标识）。
- 配合集合权限规则「仅创建者可读写」，天然实现按用户数据隔离，无需手动处理归属。

### 6.3 AI Prompt 设计

让模型返回结构化 JSON，便于前端渲染与容错：

```
你是幽默的"今日人设算命师"。根据名字「{name}」星座「{constellation}」
心情「{mood}」和今天日期，生成一份有趣的今日人设运势。
严格返回 JSON：
{ "persona":"搞笑人设(如:薛定谔的打工人)",
  "fortune":"一句话运势,要有梗",
  "yi":["宜..."], "ji":["忌..."],
  "luckScore": 0-100 }
风格:轻松幽默有网感,不低俗。
```

云函数对返回结果做 JSON 容错解析（模型偶尔可能输出非标准 JSON）。

## 8. 安全与风险

1. **AI 凭证（API Key）**：只存于云函数环境变量；禁止写入代码、提交 git、打印日志，也不要在对话中发送。
2. **数据库权限**：每个集合设「仅创建者可读写」，防止越权读取他人数据。
3. **成本控制**：云函数内加「每人每天生成次数上限」，防止恶意刷量消耗 AI 额度。
4. **内容安全**：AI 结果做敏感词兜底检查，避免不当内容。
5. **试用到期**：6 个月试用结束前关注资源额度，提前规划续费或迁移。
